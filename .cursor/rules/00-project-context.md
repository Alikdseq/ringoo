## Контекст проекта Ringoo

### Стек и принципы

- **Backend**: Django + DRF, JWT (SimpleJWT) + опционально HttpOnly cookie-режим.
- **Frontend**: Next.js (App Router) + TypeScript + TanStack Query + Axios.
- **Цель**: e-commerce. Любое изменение должно сохранять корректность потоков: каталог → корзина → checkout → заказ → личный кабинет.

### Структура репозитория (монорепо)

- `backend/`: Django проект (apps, config, integrations, tests).
- `frontend/`: Next.js приложение.
- `docs/`: документация (API, архитектура, планы, аудиты).
- `scripts/`: утилиты.

### Работа с изменениями

- Не изобретай новые паттерны без необходимости: **следуй текущей структуре** сервисов/хуков и расположению файлов.
- Перед правками: найди существующий аналог (service/hook/view/serializer) и повтори стиль.
- Если правка затрагивает API контракт: **обнови** фронтовые типы/сервисы и документацию, либо явно зафиксируй расхождение в `docs/`.
