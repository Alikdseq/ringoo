# Решение по авторизации (соответствие ТЗ)

**По ТЗ:** вход по SMS или e-mail.

**В проекте реализовано:** вход по телефону (или логину) и паролю (JWT: access/refresh). Регистрация по телефону и паролю.

**SMS-авторизация** (запрос кода, верификация) **не используется** — соответствующий код и интеграция удалены из репозитория.

**Решение:** основной сценарий — телефон + пароль; при изменении схемы входа этот документ следует обновить.
