## Сводка: что добавить/доработать

1. **Главная:** реальный блок «Популярные товары» (grid с данными из API).
2. **Поиск:** поле быстрого поиска с автодополнением в шапке и/или на главной.
3. **Каталог:** фильтр по бренду (backend + frontend).
4. **Магазины:** интерактивная карта и список магазинов на странице «Магазины».
5. **PDP:** блок/кнопка «Рассрочка» (не плейсхолдер).
6. **«Не нашли нужный товар?»:** форма на каталоге (имя, телефон, название с подсказками); поле имени в CRM; отправка на почту менеджера.
7. **«О нас»:** страница с рейтингом менеджеров; при необходимости — рейтинг в ЛК; проверка отправки ссылки на оценку после заказа.
8. **Новости:** раздел «Новости» на фронте (список + страница новости).
9. **Главная:** блок акций с реальными данными (как в разделе «Акции»).
10. **Дизайн:** акцентный цвет — зелёный по ТЗ (код из логотипа).
11. **ТЗ vs факт:** зафиксировать решение по авторизации (SMS/email по ТЗ или текущая схема телефон + пароль).
