| Принцип | Описание |

## 5. КОМПОНЕНТЫ И СОСТОЯНИЯ

### 5.1 Кнопки

- **Primary:** `background: brand`, `color: white`, `border-radius: 9999px` (pill).
- **Состояния:** hover (darken brand), active (scale 0.98), loading (spinner).
- **Размеры:** sm (36px), md (40px), lg (44px).

### 5.2 Карточки товаров

- Фон: `#ffffff`, тень: `shadow-sm`, hover: `shadow-md` + `translateY(-2px)` (лёгкий подъём, ТЗ).
- Скругления: `12px` (rounded-xl).
- Граница: `1px solid border`.

### 5.3 Модальные окна

- Плавное появление (opacity + scale), длительность ~200–250ms.
- Overlay: `rgba(0,0,0,0.5)` с backdrop-blur.

### 5.4 Чипсы фильтров

- Фон: `brand-soft` или `zinc-100`, hover: `brand`.
- Возможность удаления (крестик).

## 6. 3D-АНИМАЦИИ — ПЛАН РАЗМЕЩЕНИЯ И ПОВЕДЕНИЯ

### 6.1 Общие правила

- 3D-эффекты используются точечно для флагманских экранов и продуктов.
- Обязателен fallback для слабых устройств: видео/изображение вместо 3D.
- Определение слабых устройств: `navigator.hardwareConcurrency <= 4` или `prefers-reduced-motion: reduce`.

### 6.2 Карта размещения 3D

| Место | Описание | Поведение | Технология | Fallback |
|-------|----------|-----------|------------|----------|
| **Hero (главная)** | 3D-сцена с центральным продуктом (телефон/девайс) | Продукт вращается по оси Y (5–10°/с), при скролле — параллакс и уход вверх | Three.js + @react-three/fiber | Статичное/видео Hero-изображение |
| **Карточка товара (каталог)** | 2D-карточка | Лёгкий 3D-tilt при hover (perspective + rotateX/Y до ±5°) | CSS 3D transform | Обычный hover (подъём + тень) |
| **Карточка товара (PDP)** | 3D-модель продукта (флагманы) | Вращение мышью/тачем, смена цвета (если есть варианты) | Three.js + GLB | Галерея изображений (Swiper) |
| **Акции/промо-блок** | Баннер с 3D-элементом | Лёгкое движение (parallax) при скролле | CSS/Framer Motion | Статичный баннер |
| **Кнопка «В корзину»** | Иконка корзины | Анимация «летящей иконки» от кнопки к иконке корзины в хедере | Framer Motion (path/position) | Пульс/scale-анимация |

### 6.3 Детали реализации 3D

#### Hero 3D
- Камера: Orthographic или Perspective, начальная позиция — фронт продукта.
- Освещение: Ambient + Directional (имитация студийного света).
- Материалы: металлик, стекло (PBR) для реалистичности.
- При скролле: product position Y увеличивается, opacity уменьшается; к 40% scroll — сцена скрыта.

#### PDP 3D (страница товара)
- Включается только для товаров с флагом `has_3d_model` или категории «Смартфоны» (по настройке).
- OrbitControls: вращение мышью/тач.
- Цвет: выбор из списка вариантов обновляет материал.
- Оптимизация: Draco-сжатие GLB, LOD при необходимости.

#### Карточка каталога — 3D tilt
```css
/* Пример: perspective + transform при hover */
.card-3d {
  transform-style: preserve-3d;
  perspective: 1000px;
}
.card-3d:hover {
  transform: rotateX(var(--rotate-x)) rotateY(var(--rotate-y)) translateY(-2px);
}
```
- `--rotate-x`, `--rotate-y` вычисляются по позиции курсора относительно центра карточки.

### 6.4 Производительность 3D

- Рендер только при видимости (Intersection Observer).
- Отключение 3D при `prefers-reduced-motion: reduce`.
- Целевой FPS: 60; при падении ниже 30 — переход на fallback.

## 8. СТРАНИЦЫ — ВИЗУАЛЬНЫЕ ТРЕБОВАНИЯ

### 8.1 Главная
- Hero: full-height (min 85vh), 3D-сцена или fallback.
- Фон: градиент с `brand-soft` (низкая насыщенность).
- Кнопка CTA: brand, pill, стрелка.
- Блок «Популярные товары»: grid 2–4 колонки, карточки с hover-подъёмом.

### 8.2 Каталог
- Фильтры: боковая панель (desktop) / off-canvas (mobile).
- Чипсы выбранных фильтров над grid.
- Grid: 2 (mobile), 3 (tablet), 4 (desktop).
- Карточки: изображение, название, цена, рейтинг, кнопка «В корзину».

### 8.3 Карточка товара (PDP)
- Галерея: 3–5 фото, zoom по клику.
- Блок с ценой и CTA: «В корзину», «Купить в 1 клик», «Рассрочка».
- Таблица характеристик: zebra-подсветка строк.
- Блок наличия: список магазинов / «В наличии онлайн».

### 8.4 Корзина
- Список товаров: изображение, название, цена, количество, сумма.
- Поле промокода.
- Итог: итоговая сумма, кнопка «Оформить заказ».

### 8.5 Checkout
- Stepper: 4 шага.
- Формы: delivery, payment, подтверждение.
- Минималистичные поля, placeholder, ошибки под полями.

### 8.6 Личный кабинет
- Сайдбар-навигация (desktop) / табы (mobile).
- Карточки: заказы, бонусы, адреса, профиль.

### 8.7 Блог / Новости
- Grid статей: превью, заголовок, дата.
- Страница статьи: полный контент, дата, автор.

### 8.8 Акции
- Карточки акций с таймером (если есть ограничение).
- Цветовая подсветка: `brand`, `warning` для срочных.

### 8.9 Магазины
- Карта (Yandex Maps) с маркерами.
- Список магазинов: адрес, часы, телефон.

## 10. ПРОИЗВОДИТЕЛЬНОСТЬ И ОГРАНИЧЕНИЯ

- Все анимации: `transform`, `opacity` (GPU-friendly).
- Избегать `width`, `height`, `top`, `left` в анимациях.
- Lazy load изображений: `loading="lazy"`, `next/image`.
- 3D: отключать на слабых устройствах и при `prefers-reduced-motion`.
- Цель: Lighthouse Performance > 85.
