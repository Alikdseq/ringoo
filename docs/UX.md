# Юзабилити и UX (Ringoo)

Реализованные требования по мобильной версии, скорости восприятия и корзине/оформлению.

## Мобильная версия

- **Адаптив от 320px:** в `globals.css` задано `min-width: 320px` для `html`; контент использует относительные единицы и брейкпоинты Tailwind (`sm:`, `md:`). Всё читаемо на ширине 320px.
- **Кнопки не меньше 44×44 px:** у компонента `Button` и ключевых интерактивных элементов (меню, корзина, закрытие бургер-меню) на мобильных заданы `min-h-[44px]` и `touch-manipulation`; на десктопе (`sm:min-h-0`) сохранены обычные размеры.
- **Отсутствие горизонтального скролла:** на `body` добавлен `overflow-x-hidden` в `layout.tsx`.
- **Бургер-меню:** выезжающая панель слева (`MobileMenu`), не перекрывает контент поверх — затемнение фона и клик по нему закрывают меню. Ссылки и кнопки в меню с минимальной высотой 44px.

## Скорость восприятия

- **Скелетоны при загрузке:**
  - Каталог: компонент `CatalogSkeleton` — сетка карточек-заглушек с анимацией.
  - Корзина: скелетон из нескольких блоков (изображение, текст, кнопка) вместо одного спиннера.
- **Индикаторы загрузки:** спиннеры (`Loading` / `Spinner`) используются при подгрузке следующих страниц каталога и при отправке заказа (кнопка «Подтвердить заказ» в состоянии `loading`).
- **Понятные сообщения об ошибках:** утилита `getFriendlyErrorMessage()` в `lib/errors.ts` преобразует ответы API и сетевые ошибки в пользовательские формулировки, например:
  - 500 → «Сервер временно недоступен. Попробуйте через несколько минут.»
  - Сеть → «Не удалось выполнить действие. Проверьте подключение к интернету.»
  - 400 → «Проверьте введённые данные и попробуйте снова.»
  Используется на страницах каталога, корзины и оформления заказа.

## Корзина и оформление

- **Счётчик товаров в иконке корзины:** в хедере отображается количество позиций из `useCart()`; обновляется без перезагрузки страницы при добавлении/удалении товаров (React Query инвалидация).
- **Прогресс оформления:** на странице оформления заказа отображается степпер «Шаг N из 4» и визуальные шаги (Корзина → Доставка → Оплата → Подтверждение).
- **Вернуться к покупкам:** на странице оформления заказа добавлена ссылка «Вернуться к покупкам» (ведёт в каталог); корзина при этом сохраняется, данные шагов не сбрасываются.

## Юридические чекбоксы

- Согласие на обработку персональных данных и отдельное **согласие на рассылку** (не предотмечено) вынесены на шаг «Подтверждение» оформления заказа; в подвале в форме «Предложения для сотрудничества» также есть отдельный непредотмеченный чекбокс на рассылку. См. `docs/LEGAL.md`.
