# Как перенести проект Ringoo в папку без кириллицы в пути

Пошаговая инструкция, чтобы перенести весь проект в путь только с латинскими буквами (например `C:\Projects\Ringoo`) и избежать ошибок с кодировкой (UnicodeDecodeError при миграциях и т.д.).

---

## Шаг 1. Закрыть всё, что использует проект

1. Закройте **Cursor** (или другой редактор), если открыт проект Ringoo.
2. Закройте все **терминалы**, где вы запускали `python manage.py`, Docker, сервер и т.д.
3. Если запущен **Docker** с контейнерами Ringoo — остановите:
   - Откройте терминал в папке проекта и выполните:  
     `docker-compose down`  
   - Или закройте Docker Desktop.

Так мы избежим блокировки файлов при копировании.

---

## Шаг 2. Создать новую папку без кириллицы

1. Откройте **Проводник** (Win + E).
2. Перейдите на диск **C:** (или другой диск, где хотите хранить проект).
3. Создайте папку с именем **только из латинских букв и цифр**, например:
   - `C:\Projects`
   - или сразу `C:\Projects\Ringoo`
   - или `C:\Dev\Ringoo`

**Как создать папку:**
- Правый клик в пустом месте → «Создать» → «Папку».
- Введите имя, например: `Projects` или `Ringoo`.
- Нажмите Enter.

Если создали только `C:\Projects`, откройте эту папку и создайте внутри ещё одну папку с именем `Ringoo`.  
Итог: у вас должна быть папка вида **`C:\Projects\Ringoo`** (без русских букв в пути).

---

## Шаг 3. Скопировать весь проект в новую папку

1. В **Проводнике** откройте **Рабочий стол** (Desktop).
2. Найдите папку **Ringoo** (ваш текущий проект).
3. **Выделите** папку Ringoo (один клик по ней).
4. Нажмите **Ctrl + C** (копировать).
5. Перейдите в папку, которую создали в шаге 2 (например `C:\Projects`).
6. Нажмите **Ctrl + V** (вставить).

Дождитесь окончания копирования. Внутри должна быть та же структура: `backend`, `frontend`, `docs`, `docker-compose.yml` и т.д.

**Важно:** мы именно **копируем** проект. Старую папку на рабочем столе пока не трогаем (её можно удалить после проверки, что всё работает).

---

## Шаг 4. Открыть проект в Cursor из новой папки

1. Запустите **Cursor**.
2. Меню **File** → **Open Folder** (или **Файл** → **Открыть папку**).
3. Перейдите в **`C:\Projects\Ringoo`** (или туда, куда вы скопировали проект).
4. Выберите папку **Ringoo** и нажмите **«Выбор папки»** / **Select Folder**.

Теперь вы работаете с проектом из пути без кириллицы.

---

## Шаг 5. Проверить, что в новой папке есть нужные файлы

В левой панели Cursor (Explorer) убедитесь, что видите:

- Папку **backend** (внутри: `manage.py`, `apps`, `config`, `requirements.txt` и т.д.)
- Папку **frontend**
- Папку **docs**
- Файлы в корне: **docker-compose.yml**, **README.md**, **PLAN.md** и др.

Если чего-то нет — значит, копирование было не из той папки; повторите шаг 3 из правильной папки Ringoo.

---

## Шаг 6. Настроить окружение в новой папке (если нужно)

1. В Cursor откройте папку **backend**.
2. Проверьте, есть ли файл **`.env.development`** (он может быть скрыт).
   - Если его нет — скопируйте из **старой** папки Ringoo с рабочего стола:  
     `C:\Users\Алихан\Desktop\Ringoo\backend\.env.development` →  
     `C:\Projects\Ringoo\backend\.env.development`
3. В **`.env.development`** для запуска с вашего ПК (не из Docker) должно быть:
   - `DB_HOST=localhost`
   - Остальное можно оставить как было (DB_NAME=ringoo, DB_USER=postgres, DB_PASSWORD=postgres, DB_PORT=5432).

Сохраните файл (Ctrl + S).

---

## Шаг 7. Запустить миграции из новой папки

1. В Cursor откройте **терминал** (Terminal → New Terminal или `` Ctrl+` ``).
2. Перейдите в папку backend:
   ```bash
   cd backend
   ```
3. Выполните миграции:
   ```bash
   python manage.py migrate
   ```

Если всё настроено и PostgreSQL запущен (локально или в Docker с портом 5432), миграции должны пройти без ошибки `UnicodeDecodeError`.

**Если используете Docker:** сначала в корне проекта выполните `docker-compose up -d db`, затем в `backend` — `python manage.py migrate` (и в `.env.development` оставьте `DB_HOST=localhost` для запуска с хоста).

---

## Шаг 8. Дальше всегда работать из новой папки

- Всегда открывайте в Cursor папку **`C:\Projects\Ringoo`** (или тот путь, куда вы скопировали проект).
- Все команды (`python manage.py`, `docker-compose`, `make` и т.д.) запускайте из этого места.
- Git-репозиторий (история коммитов) уже внутри скопированной папки — можно продолжать работу как раньше.

---

## Шаг 9. (По желанию) Удалить старую папку с рабочего стола

Делайте это **только после того**, как убедитесь, что из новой папки всё работает (миграции, запуск сервера, Docker и т.д.).

1. Закройте Cursor и все терминалы.
2. В Проводнике перейдите на рабочий стол и найдите старую папку **Ringoo**.
3. Удалите её (правый клик → Удалить или клавиша Delete).
4. При необходимости очистите корзину.

После этого единственная актуальная копия проекта — в пути без кириллицы (например `C:\Projects\Ringoo`).

---

## Краткая шпаргалка путей

| Где было (пример)              | Куда перенести (пример)   |
|-------------------------------|---------------------------|
| `C:\Users\Алихан\Desktop\Ringoo` | `C:\Projects\Ringoo`      |

Дальше всегда открывайте и работайте с **`C:\Projects\Ringoo`**.

---

## Если что-то пошло не так

- **«Папка занята» при копировании** — закройте Cursor, все терминалы и Docker, затем повторите копирование.
- **Миграции снова выдают ошибку** — проверьте, что терминал и Cursor открыты именно из `C:\Projects\Ringoo\backend`, а не из старой папки на рабочем столе.
- **Не видно `.env.development`** — в Проводнике: Вид → Показать → Скрытые элементы. Или скопируйте файл вручную из старой папки в новую (в `backend`).
