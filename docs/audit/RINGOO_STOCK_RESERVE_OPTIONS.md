# Ringoo ↔ 1С: остатки и резервы

**Дата:** 07.11.2026
**Статус:** варианты для согласования (логика Ringoo **не менялась**)

## Текущая модель в Ringoo

| Поле | Смысл |
|------|--------|
| `Stock.quantity` | Фактический остаток (для товаров с `onec_code` — из импорта 1С) |
| `Stock.reserved_quantity` | Резерв интернет-заказов Ringoo |
| `available_quantity` | `max(0, quantity - reserved_quantity)` |

Импорт: `apply_onec_stock_upsert` обновляет **quantity** (и серии), не трогая бизнес-резервы без явной политики.
Резерв заказа: `apps.stores.stock_ops` (`reserve_*` / release при отмене / истечении).
В 1С **не отправляются** изменения остатков с сайта.

## Вариант A — резерв только в Ringoo (текущий)

- 1С отдаёт «сырой» остаток склада.
- Ringoo вычитает свой `reserved_quantity` для витрины и checkout.
- **Риски:** если в 1С тот же товар продают офлайн без учёта резерва сайта — возможна перепродажа; двойного списания в Ringoo нет (резерв атомарный), но рассинхрон с физическим складом возможен.
- **Плюс:** не нужен двусторонний API остатков.

## Вариант B — передача резерва в 1С

- После резерва/оплаты Ringoo шлёт в 1С документ резерва/заказа.
- **Риски:** нужны идемпотентность, отмена резерва, SLA; иначе двойной резерв или «зависший» резерв в 1С.
- **Требует:** контракт POST от владельца 1С (не реализован на сайте).

## Вариант C — актуальный остаток из 1С + отдельный резерв Ringoo

- Частый poll остатков из 1С; Ringoo продолжает держать `reserved_quantity`.
- **Риски:** гонка между импортом quantity и локальным резервом (нужно правило: импорт не обнуляет reserved; available = qty − reserved).
- **Плюс:** ближе к «истине склада», если офлайн-продажи идут в 1С.

## Что подтвердить владельцу 1С / склада

1. Учитывает ли 1С уже интернет-резервы Ringoo?
2. Нужен ли документ резерва/заказа в 1С до оплаты?
3. Как часто допустим poll остатков без нагрузки на 1С?
4. Что делать при временном отсутствии позиции в выгрузке (Ringoo **не удаляет** строки сейчас)?
5. Серии (`onec_series_id`): обязательны ли для всех SKU?

**Решение до согласования:** не менять резервы Ringoo и не писать остатки обратно в 1С.
